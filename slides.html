The Foundation

What is Gen3 & Why Use It?

What is Gen3?

  • Open-source data platform.
  • Share, host, and explore complex data.
  • Built entirely from microservices.
  • Strictly schema-driven architecture.

Why Gen3?

  • Discoverable

    Promotes FAIR data principles across cohorts.

  • Governed

    Fine-grained access control for sensitive data.

  • Federated Analysis

    Analyse data where it lives without duplication.

Infrastructure & Architecture

Moving from cloud-dependency to a robust, bare-metal cluster.

Bare Metal Server

  • 32 vCPUs
  • 62 GB RAM
  • Local Object Storage (MinIO)

Kubernetes Cluster

Lightweight orchestration using k3s to manage the containerised environment.

Microservices

18 containerised services acting as the basis of the platform, interacting seamlessly.
